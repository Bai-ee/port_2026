What's maybe not necessary

1 · Brief proliferation (highest impact). Executive Daily Brief + 5 sliced briefs (Competitor/Marketing/Strategy/Creative/Performance) + 2 onboarding brief docs = 8 brief surfaces from one engine. Each slice duplicates an existing card (Competitor Brief ≈ Competitor Snapshot; Strategy Brief ≈ Strategy Builder; Creative Brief ≈ Design Brief; Performance Brief ≈ SEO cards). Collapse to 1 Executive Brief + tabs.
2 · Platform/source config sprawl. Search Plan, Web Search + Platforms, Social Media Signals (growth) + Platform Coverage (social) all configure the same source list. Collapse to one Source Platforms card.
3 · Duplicate "Homepage Mockup." Exists in both Creative Director (client-mockup-creative) and Website Developer (client-mockup). Keep one.
4 · Two performance cards. SEO + Performance Snapshot vs Site Performance — same PSI data. Merge.
5 · Strategy output overlap. Next-Post Strategy, Content Gaps, Posting Rules all render brief-derived strategy. Consider one "Strategy" card with sections.
6 · Verify Automation tiles. Content Engine / Automation Opportunities / Reporting & Insights — confirm they're wired to data vs upsell placeholders; if placeholder, gate behind a tier instead of occupying card slots.
Net: ~77 cards could likely become ~50 without losing capability — mostly by collapsing brief slices and source-config duplicates into tabbed cards.
