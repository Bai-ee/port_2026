## 8. Inventory (content packages)

Each owned-record birthday artist has an x_content_packages row named birthday-<artist> (series C1, record engine): artist name plus alias (Sound Design, Yonkapin, Big Bang Theory) and label in "entities", the birth date as "eventDate", the Discogs release id and link in "source", mediaState "needs-capture". The matcher's anniversary rule (within 2 days of the date) can find them by name; showcase slots still need a filmed clip before one is proposed automatically. The matching unscheduled drafts carry the same packageId.
