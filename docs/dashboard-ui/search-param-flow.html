Brand Identity → Search Pipeline — Full Flow

Signup crawls the site and writes the canonical brand identity into scoutConfig (store A). Cards seed from it, stay editable, and every run reads it back. Card edits mirror B→A on save; runs read A-first — so the audit, Scout Test, external scouts, and the Brief Run all resolve to one identity. File:line refs are real.
