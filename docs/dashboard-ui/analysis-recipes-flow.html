Market Signals · Analysis Recipes

How analysis skills plug into the Market Signals pipeline.

An "analysis recipe" is an imported marketing skill run as a swappable prompt over content Scout already gathered. Recipes are analyzers, not data fetchers — they never replace Scout. This page maps the data pipeline, how a skill is added, what it returns, and how to read it.

03 · How to add a skill into the flow

Drop the prompt asset

Add <id>.md in features/intelligence/analysis-recipes/ — YAML frontmatter (id, label, source, mode: analyzer, inputs, output) then the prompt body. The body must define a strict output contract: raw JSON object first (no code fence), one blank line, then <200-word prose. Grounding rule is mandatory — every claim traces to a supplied item or is omitted.

Register it

Add an entry to RECIPES in recipes.js (id, label, description, file, source, model, maxTokens). It now auto-appears in the SOURCES "04 · Analysis Skills" toggle list — the card reads the catalog from GET /api/dashboard/recipe-run, it never hardcodes a list.

Decide the render

Synthesis-shaped output (themes/JTBD/vocabulary/alternatives/contradictions/dataQuality) → renderRecipeBriefBlock renders it with no UI change. A custom shape → add a render fn (pattern: renderWatchlistAnalysisBlock) and branch to it in renderSignalsBriefMock.

Prove, then wire

Validate on real data with the CLI before toggling: node features/intelligence/analysis-recipes/run-recipe.js --recipe <id> --content ./scoutBrief.json. Then toggle ON in the card and Run enabled. The swap-slot doubles as an A/B mechanism — two recipes over the same content compare side by side in REPORT.

04 · Synthesis output schema (customer-research)

// raw JSON first (no fence), blank line, then <200-word prose
{
  "themes": [
    { "name", "summary", "frequency":int, "intensity":"high|medium|low",
      "confidence":"high|medium|low",
      "quotes":[{ "quote", "source", "url" }],
      "implication" // the "so what" — the marketing instruction }
  ],
  "jobsToBeDone": [{ "functional", "emotional", "social" }],
  "vocabulary":   [ "exact customer phrase" ],   // copy gold — use verbatim
  "alternatives": [ ... ],   // competitor / DIY / nothing → comparison pages
  "contradictions":[ ... ],   // say one thing, imply another → test these
  "dataQuality": { "itemsAnalyzed":int, "overallConfidence":"...", "gaps":[ "what we still don't know" ] }
}

The REPORT render surfaces every field, in reading order: Summary → Themes → Jobs to be done → Customer vocabulary → Alternatives → Contradictions → What we still don't know.

05 · How to read & leverage it

Read confidence first, act second. A theme is only as trustworthy as its sourcing.

ConfidenceCriteriaWhat to do
HighTheme in 3+ independent items, unprompted, consistentShip into headline / positioning — decision-grade.
Medium2 items, or only prompted, or one segmentUse directionally; validate before betting budget.
LowSingle item; possible outlierTreat as a hypothesis; broaden sources to confirm.
Themes → angle

High-confidence + high-intensity theme = your headline. The "So what" line is already the messaging instruction.

Vocabulary → copy

Paste exact phrases verbatim into ads, landing pages, post hooks. Don't translate to corporate ("drowning in spreadsheets" > "process inefficiency").

JTBD → value props

Functional = feature copy · emotional = tone · social = status/identity framing.

Alternatives / Contradictions

Alternatives → comparison + switching-cost pages. Contradictions → where to dig or run a test; don't trust stated preference at face value.

Gaps → next research

Each "what we still don't know" is the next Scout query. Close a gap → raise the next run's confidence.

Sample bias

Reddit skews skeptical, reviews skew negative, forums skew power-users. A single-source theme isn't "all customers" — that's why it's tagged Low.

06 · Better input → better synthesis

Recipes only analyze what Scout supplied. Confidence = frequency × independent sources, unprompted voice only. These SOURCES knobs move the output:

categoryTerms

Drives the PAIN POINTS + CATEGORY queries → biggest lever for themes, pains, vocabulary. Use how customers describe the space, not your internal label.

competitors

Feeds the COMPETITORS query → fills Alternatives + Contradictions. Empty = those sections stay empty.

brandKeywords

Catches direct mentions → brand pains + money quotes. Add misspellings, product names, abbreviations.

watchlist handles

KOL voice. Track people who talk to your buyers, not just big accounts. Quality > quantity.

custom searches

Where you raise confidence on purpose — add unprompted-voice patterns: "wish there was", "switched from", "anyone recommend".

source diversity

X + Reddit + reviews promotes Low → High faster than more queries on one platform. One thread 5× is still one source.
