Anatomy of the Executive Brief.

One brief is not one document. It is a composition — an ordered selection of registered sections, each fed by its own data layer, assembled on demand and gated by tier.

01 · Aggregation

Where the content comes from.

Every section pulls from exactly one of six data layers. Layers are produced at different times — some at intake, some by the AI pipeline, some live at render.

Crawl + Edit Snapshot Site evidence crawled, brand overview synthesized, then merged with user edits. Survives reruns.
Deterministic Module Briefs Six audit mini-summaries (SEO, agent readiness, devices, social preview, style guide, design eval) compiled without an LLM. Missing modules get explicit NO DATA entries.
AI Pipeline Scout Brief Narrative brief plus agent data: KOL activity, category trends, competitor intel, Reddit and local demand signals, brand mentions, viral windows.
AI Pipeline Strategy 30-day rolling campaign, today's content move, posting angles and revision notes.
User Config Client Config Research parameters: brand keywords, category terms, competitors, watchlist KOLs, search focus, local signals, events.
Live at Render Weather + Social Queue Local weather API and the scheduled post queue, fetched fresh when the brief renders.
▼ assembled by composition ▼
Output Rendered Brief Single HTML document: ordered sections, responsive CSS, print pagination, pinned email CTA.

04 · Entitlements

Tier gating at a single point.

Access is checked once — isBriefAllowed(tier, briefType) — at the preview route. Denied briefs return a 403 upgrade page; the dashboard renders them as locked cards.

Admins bypass the tier check entirely, via an email lookup against the admins collection.

05 · Assembly Pipeline

From crawl to rendered page.

Four stages. The first two produce durable data; the last two compose and deliver it.

Intake run

The free-tier intake pipeline runs the enabled audit modules, builds the six deterministic moduleBriefs, crawls site evidence, synthesizes the brand overview, and merges it with any user edits. It then queues a chained scout-brief run.

Scout-brief run

The AI pipeline receives the module briefs (folded into the Scribe prompt) and produces the marketing brief narrative, agent data, and the 30-day strategy — all persisted to dashboard_state.

Composition + gating

The preview route reads ?brief=<key>, resolves the named composition (default executive-daily), and checks tier entitlement. Denied access renders the upgrade page instead.

Render

The route aggregates all six layers — dashboard state, client config, module briefs, live weather, and the social queue — and renders the ordered sections as a single HTML document with responsive and print CSS.

06 · Delivery Surface

How the brief reaches the reader.

The rendered brief carries its own delivery affordances.

Email CTA

A pinned Send to my email button with an animated border, hidden in print. It posts a message to the parent dashboard iframe to trigger the subscribe flow.

Dashboard previews

Dashboard cards map to composition keys via BRIEF_TYPE_BY_CARD. A click opens the brief fullscreen; tier-locked briefs show a lock and upgrade prompt instead.

Responsive + print

Grid collapses to one column under 900px, stat rows restack under 640px, and each section becomes its own page when printed.
